# Archived planning documents

These were written before the app was built. They describe an earlier plan
(file names like `furrow-*`, a 15-minute setup, features that didn't exist yet)
and are **out of date**. They're kept for the background they give, such as
the partner profit-split options in `DYLAN_PARTNER_SETUP.md`.

For how the app actually works and how to set it up, see the main
[`README.md`](../../README.md) and [`supabase/README.md`](../../supabase/README.md).
